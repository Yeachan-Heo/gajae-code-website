gjc rlm was removed

In 0.15.0 the bundled team workflow and gjc rlm command were replaced by the research-only autoresearch skill. Team-style worker coordination is IRC, not a fifth default skill.

Where to go

Use Autoresearch for web research, REPL/data experimentation, and a structured verdict. Use a normal gjc session with deep-interview, ralplan, and ultragoal for implementation.

Commands removed: gjc rlm and gjc team are not on the 0.15.0 surface. Existing Team/RLM automation must move to Autoresearch and the approval-gated execution skills.
